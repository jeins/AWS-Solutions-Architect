# AWS Solutions Architect Associate (SAA-C03) - Bahasa Indonesia

> Catatan pembelajaran AWS untuk developer Indonesia, dengan fokus pada keputusan arsitektur, keamanan, biaya, dan contoh Java/Spring Boot.

## Pola pembelajaran

1. Baca materi lengkap per section, pahami istilah AWS tanpa harus menerjemahkan nama layanannya.
2. Terapkan prinsip desain pada contoh sistem nyata, khususnya backend Java/Spring Boot.
3. Kerjakan seluruh quiz modul sebelum membuka kunci jawaban.
4. Periksa [pembahasan](01-aws-fundamentals/ANSWER-KEY.md) untuk memahami *mengapa* pilihan lain kurang tepat.
5. Cek perubahan fitur dan harga AWS langsung ke dokumentasi resmi sebelum menerapkan contoh pada production.
